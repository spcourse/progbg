# Style

Until now, your code has been evaluated solely based on whether the solution is correct. However, correctness is only one aspect of good programming. Readability, maintainability, and simplicity are also important.

In this assignment, you won’t be solving a new problem. Instead, you will revisit and improve `exploration.py`, the program you built in *Read Data*, *Scatter Plot* and *Manual Fitting*. Your goal is to refine the style and design of your code, making sure it follows best practices and is easy to understand. The program should still produce the same output as before.

## Style

Ensure your code fully complies with our [style guide](/python/en/style). Pay special attention to:

- [Comments](/python/en/style#comments)  
- [Variable naming](/python/en/style#variables)  
- [Indentation](/python/en/style#indentation)  
- [White spaces](/python/en/style#blank-lines-and-extra-spaces)  
- [Pure functions](/python/en/style#pure-functions)  

## Design

Structure the program thoughtfully and use functions to keep your code organized. Your file already contains `apply_affine` and `mse`, but consider adding more helper functions to further improve the code structure.

## Evaluation

Your assignment will be graded manually, on both style and design.
